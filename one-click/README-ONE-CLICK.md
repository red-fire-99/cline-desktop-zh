# Cline 桌面版 一键汉化包（中文界面）

> 零代码基础也能用：下载 → 解压 → 双击安装 → 双击快捷方式启动中文 Cline

## 一、这是什么？

Cline 是一款强大的 AI 编程助手，但官方桌面版默认是英文界面。

本“一键汉化包”不修改 Cline 原程序，而是通过 **CDP 调试协议** 在运行时把界面文案替换成中文。安装后不写注册表、不占用系统目录，直接删除本文件夹即可彻底卸载。

## 二、系统要求

- Windows 10 / Windows 11
- 已安装 **Cline 桌面版**（从 https://cline.bot 下载）
- 联网（首次运行需下载约 40MB 的 Node.js 运行环境）

## 三、使用步骤（新手也能几分钟搞定）

### 第 1 步：下载并解压
从 [Releases](../../releases) 页面下载最新的 `cline-desktop-zh-one-click.zip`，解压到任意文件夹（例如 `D:\Cline-ZH`）。

> 建议解压到路径**不含中文**的位置，避免个别老系统出现乱码。

### 第 2 步：运行一键安装
双击文件夹里的 **`one-click-setup.ps1`**（如果提示“无法运行脚本”，请右键点击 → “使用 PowerShell 运行”）。

脚本会自动：
1. 检测你电脑上已安装的 Cline 桌面版；
2. 下载并配置便携版 Node.js（约 40MB，仅首次需要）；
3. 在桌面和开始菜单创建 **“Cline 中文版”** 快捷方式。

### 第 3 步：启动中文 Cline
以后每次使用，直接双击桌面上的 **“Cline 中文版”** 快捷方式即可。它会：
- 自动启动 Cline（若未运行）；
- 以中文语言和调试端口启动 Cline；
- 后台自动注入中文词典，把界面翻译成中文。

> 如果 Cline 已经在以英文模式运行，脚本会提示你关闭并重启为中文模式，点“是”即可。

## 四、卸载

直接删除整个汉化包文件夹即可，不留任何系统垃圾。快捷方式可随手删掉。

## 五、原理（可选阅读）

本包不修改 Cline 可执行文件，而是：
1. 以 `--remote-debugging-port` 启动 Cline，开启本地调试端口；
2. 通过 Chrome DevTools Protocol (CDP) 连接 Cline 的 WebView 页面；
3. 将界面英文文案替换为中文词典（`dict/zh-cn.json` + `dict/fragments.json`）。

每次 Cline 更新后，如出现新的未翻译文案，可更新词典后重新运行安装脚本即可。
